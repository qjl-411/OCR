## 独立测试与去重协议

原 0081–0100 与训练或开发集包含相同发票的不同照片，因此只能保留为图片留出结果。根据原图印刷票号人工审查全部 100 张照片，使用相同票号保守分组；排除训练、开发及全部历史评估 0001–0025、0051–0100 的所有票据身份。剩余 0030、0035 在模型首次处理前被固定，两张照片同属一张新发票。分组、完整排除和模型/输入/实现哈希均留档。不得将两张相关照片当作两张独立发票。

另在官方文档中选择两份固定示例，首次推理前人工抄录六项字段 GT。两份原图均未参与本项目训练或调参，不调用厂商 OCR；不推定其为经核验的真实交易。其票号与附件和 VATID 的所有分组不同。全部独立集合计四张图、三张不同发票，规模不足以说明普遍效果。

## 指定网络关键词结果

模型版本 `ctpn-crnn-ctc-camera1200-r1`。VATID 两张图，60 个关键词，水平 50、竖排 10。只执行 CTPN / CRNN / CTC，无 PDF 文字层、PP-OCR 或人工输出修订。

| 指标 | 计数 | 实测结果 |
| --- | --- | --- |
| 水平关键词检测覆盖召回 | 42 / 50 | 84.00% |
| 水平 GT 裁剪整词匹配 | 50 / 50 | 100.00% |
| 水平 GT 裁剪 CER | 0 / 176 | 0.00% |
| 水平端到端关键词召回 | 29 / 50 | 58.00% |
| 全部关键词端到端召回 | 29 / 60 | 48.33% |
| 竖排端到端关键词召回 | 0 / 10 | 0.00% |

GT 裁剪识别使用人工真值框，只是 CRNN+CTC 组件指标，不能称为整票准确率。检测覆盖指预测行框覆盖至少 80% 的关键词真值框面积；端到端还要求预测文本包含该关键词。双方 NFKC 后去除标注未包含的标点和空格。没有完整票面标注，不能计算全票精确率或 F1。原始详情：independent-classic-results.json。

## 验收边界与剩余事项

三张新票的样本规模很小，上游预训练数据未完整公开，也无法排除原模型预训练重叠。低分辨率票头、长数字、密集表格与竖排仍有明显失败。输入和权重均保留哈希；此轮最终测试后未再修改网络、预处理或字段解析，所有成功与失败一并保留。

Windows 原生与真实浏览器（桌面 + 移动端）已于 2026-11-21 在本机实际执行通过，截图与日志见 [验收执行记录](11-acceptance-execution.md)。当前 GitHub 未登录、Docker CLI 不可用、本机无 macOS，因此 macOS、容器和 GitHub Actions 远程作业仍未执行。源码、脚本和 CI 已准备，但不能把“有配置”写成“已通过”；这三类需在有对应环境的运行器上完成真实运行后才可形成全平台验收结论。
