# 票序界面设计规范

## 视觉方向

商务级财务工作台风格：浅灰画布、白色卡片、深松绿主色，辅以中性灰阶区分层级。
中文使用系统无衬线字体；金额使用等宽数字。图标采用统一线条图标，避免装饰性图片影响票据可读性。

设计目标是**可交付给企业客户**，因此界面只呈现使用者需要的信息：算法型号、数据来源、接口文档等技术细节不出现在最终用户界面中；面向验收或运维的内容保留在项目文档内。

桌面左侧 238px 常驻导航，顶部为位置、搜索入口、工作区标识与当前用户。内容区域包含页标题、操作、关键数据卡与主要工作区。窄屏导航收起到抽屉，表格保持横向滚动。

## 登录与注册

未登录时进入独立的认证页，不渲染任何业务界面。

| 区域 | 内容 |
| --- | --- |
| 品牌侧栏 | 产品标识、主标题、价值主张三条（数据不出本机 / 批量自动整理 / 支出结构清晰） |
| 表单卡片 | 登录与注册双 Tab、输入校验、密码强度指示、密码显隐、记住我、忘记密码入口 |
| 注册字段 | 姓名、公司名称、邮箱、密码（至少 8 位） |

会话保存在浏览器 `localStorage`；应用启动时校验会话，无会话则停留在登录页。侧栏提供「退出登录」入口。

## 页面规划

页面职责互斥：**任意两页不出现相同内容块**。

| 页面 | 主要内容 | 关键交互 |
| --- | --- | --- |
| 登录 / 注册 | 品牌介绍、表单校验、密码强度 | 登录、注册切换、邮箱验证码、会话写入与清除 |
| 工作台 | 金额指标卡、支出趋势折线、费用构成环图、最近导入、复核待办 | 来源切换、打开票据、跳转台账、导出 |
| 识别中心 | 左侧上传区（扫描件识别开关、拖拽上传、待上传队列）、右侧识别任务列表 | 多文件 ZIP、真实进度、错误重试、批次明细 |
| 发票台账 | 搜索、状态标签、分类、日期、分页、勾选；标签页切换全部/待复核/已确认/重复/异常/已驳回 | 详情、批量导出、删除确认 |
| 分析报告 | 供应商支出排行、费用结构占比表、月度支出明细表、票据构成 | 时间与来源筛选、导出当前范围 |
| 操作记录 | 时间、动作、票号、字段变更 | 按动作筛选、审计追踪 |
| 系统设置 | 工作区设置、复核规则、使用帮助、数据与隐私、可用数据集 | 持久保存复核阈值与工作区名称 |

**内容分工约定**：趋势图与费用构成环图只出现在工作台；供应商、分类明细、月度明细与票据构成只出现在分析报告；复核表单在弹窗内，不单独占页。

**识别中心版式**：采用左右两栏等高布局——左栏为上传区，右栏为识别任务列表。页面本身不产生滚动，
任务列表在栏内独立滚动，因此一批任务再多也不会把页面向下撑长。教学性质的辅助卡片（示例数据引导、
识别小贴士）不进入交付界面；上传区顶部以一行说明可接受的格式与批次上限。

**引擎选择不进入界面**：指定的 CTPN / CRNN / CTC 由服务端固定使用，界面上只保留"扫描件 PDF 按图片识别"
这一个与用户文件形态直接相关的开关。让最终用户选择 OCR 算法既超出使用场景的需要，也可能误选到
对照通道而偏离指定网络；`pipeline` 参数在 API 层保留，供验收与对照测试使用。

## 设计细节

主色 `#123a2d`，画布 `#f6f7f9`，正文 `#16241e`，次级文字 `#74838d`，边框 `#e6eaee`。
字重只使用 400 与 500；主字号 29px，标题 16–17px，正文 13.5–14px，辅助信息不小于 12.5px。
圆角 8–18px，卡片分三级阴影（sm / md / lg），主区域留白 30–42px。

设计 token 定义在 `frontend/src/theme.css`，作为 `styles.css` 之后的覆盖层；登录页样式独立于 `frontend/src/auth.css`。

所有操作有明确的等待、成功、失败反馈；按钮在请求中禁用；弹窗支持 Escape、焦点约束与关闭；文件状态与异常同时使用文字和颜色表达。金额、票号与状态列位置稳定，票据复核时始终保留原始识别文本与人工修改记录。
