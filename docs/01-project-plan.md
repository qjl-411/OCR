# 项目脉络与交付范围

原题要求电子发票读取、CTPN 检测、CRNN 识别、CTC 解码、信息提取和 Excel 保存。Qt 界面经用户授权改为前后端；指定算法仍须实际执行，不能只保持抽象职责相同。

| 阶段 | 工作与交付物 | 验证 |
| --- | --- | --- |
| 立项 | 对照原题、盘点 23 个 PDF、区分真实和合成数据 | 文件清单、范围说明 |
| 设计 | 七个业务页面、复核工作区、数据和 API 边界 | 页面设计、类型检查 |
| 基础实现 | 上传、PDF 提取、队列、SQLite、预览 | API 与文件测试 |
| 指定检测 | 原始 CTPN 权重转换和后处理 | 三尺寸原始输出对齐 |
| 指定识别 | 经典 CRNN 与两阶段有监督微调 | 逐步 loss、检查点哈希 |
| 解码和提取 | CTC、证据框、金额与格式规则 | 标签级与字段测试 |
| 业务完善 | 人工复核、版本保护、重复限制、统计、审计、导出 | 完整业务闭环 |
| 独立评估 | 固定未见纸票，分开组件与流水线指标 | 输入、模型和代码哈希 |
| 环境验收 | Linux、Windows、macOS、容器、真实浏览器 | 实际记录，不以配置代替结果 |

保留旧版 PP-OCR 对比通道，但默认图像引擎为 CTPN / CRNN / CTC。补充功能包括批量 ZIP、重复票阻止确认、金额一致性、来源筛选、人工修改退回复核、统计和审计。项目面向个人单机与课程演示，不将其描述为税务查验服务或多人生产平台。
