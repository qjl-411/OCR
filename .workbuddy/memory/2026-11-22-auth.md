  → 无效令牌拒绝，账号已落库（bcrypt `$2b$12$`）。

### 又修的两个邮件实现缺陷
1. `message['Subject'] = Header(...)` 后取值抛 `'Header' object is not subscriptable`
   → 直接赋 UTF-8 字符串。
2. 模板用 `str.format()` 渲染，CSS 大括号被当占位符 → `KeyError: 'margin'`。
   → 改用 `@@CODE@@` 占位符 + `replace()` 渲染。
